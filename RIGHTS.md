## Sources tierces

Le socle Sim provient du dépôt officiel https://github.com/simstudioai/sim au commit `c6cef5f87b6a1d1d01df89e7140bad9e9fd4c2e2`. Les fichiers réutilisés conservent leurs droits et leurs notices Apache-2.0, disponibles sous `compliance/upstream/sim/`. Les licences imbriquées restent à leur emplacement. Les textes de licence des bibliothèques ne sont pas remplacés par les présentes indications.

Le répertoire Enterprise `apps/sim/ee`, les empreintes Enterprise interdites, les polices Season Sans et Söhne et les archives/exécutables opaques non admis sont exclus de cet export. Le dépôt ne distribue pas actuellement les moteurs OpenAdapt ; leur intégration est en cours de développement.

Les fichiers Sim adaptés portent une mention de modification Memlia. Cette mention conserve la licence et les droits sur le code tiers ; elle n’affirme pas que Memlia est propriétaire du code amont. Les noms et signes d’autres éditeurs restent leurs marques. Leur présence comme référence technique, attribution ou élément d’amont ne constitue aucun droit de marque pour un produit commercial.

Les adaptations incluent les contrats et lecteurs de révision du workflow, les primitives de persistance et de collaboration, les hooks optionnels des providers, les métadonnées CLI régénérées et l'alignement Next16.4.2. Les tranches suivantes ajoutent les attestations clientes des snapshots et le raccordement serveur des lectures autorisées aux providers, sans activer de route Chat ni revendiquer un produit complet. Le scope personnel des contrats représente explicitement une organisation absente par `null`, sans accorder de droits. Les fichiers JSON modifiés portent une propriété `x-memlia-modifications`, sans commentaire JSON invalide. Les lecteurs natifs de Drizzle acceptent cette extension sans produire de SQL ni changer les migrations lues : `packages/db/migrations/meta/0435_snapshot.json`, `0436_snapshot.json` et `_journal.json` décrivent les extensions de schéma Memlia et leur journal ; `packages/testing/src/mocks/schema-tables.generated.ts` est régénéré depuis ce schéma adapté. Les manifestes `package.json`, le verrou Bun et le manifeste du package workflow-persistence reflètent les dépendances et exports modifiés. Ces éléments dérivés gardent les droits amont applicables ; les ajouts originaux restent distincts ci-dessous. Les textes de licence et NOTICE Sim sont inchangés. Les adaptations suivantes conservent les sauvegardes natives tout en ajoutant leur révision attendue aux parcours import/auto-layout, et partagent la préparation de payload sans changer les décisions d’exécution legacy. Les nouveaux modules de politique Chat, clients contrôlés et primitives de sessions/admission/livraison ne donnent aucune autorité implicite et n’activent pas un service externe. Les notices des fichiers Apache modifiés sont conservées ; les nouveaux fichiers Memlia restent sous droits réservés.
